Sources and how each figure is used

  • Loading…

Rules we follow: no figure without a source and a year; older editions stay labeled with their own year rather than relabeled; when no publishable figure exists the table shows a dash, not an estimate. The 2025 reference set the Cost Lab used before this release remains available as rates-2025.json (historical). Corrections: open an issue.

Using these figures responsibly

SUTA rates depend on each employer’s experience and, in some states, surcharges our base-rate figures exclude (the table says which). Workers’ comp depends on class codes, carrier and loss history; an index is not a rate anyone can buy. Health figures are survey averages for single coverage; family coverage and plan design move cost substantially.
